🚗 Gestor Veicular

Projeto Integrador - Aplicativo de gestão veicular que integra o diagnóstico de telemetria via scanner OBD-II a um comparativo inteligente de preços de oficinas locais.

📖 Sobre o Projeto

O Gestor Veicular é uma solução acadêmica desenvolvida para conectar o diagnóstico técnico do veículo à gestão financeira do motorista.

Muitos motoristas ficam vulneráveis a preços abusivos ou diagnósticos incorretos ao visitarem oficinas mecânicas. Através da leitura de dados via porta OBD-II, nosso aplicativo traduz a saúde do veículo em tempo real e cruza esses alertas com um comparativo de orçamentos de oficinas parceiras em um raio de até 20 km. O objetivo é garantir transparência técnica e financeira, além de modernizar a captação de clientes para os mecânicos.

✨ Principais Funcionalidades

O sistema foi desenhado para atender a dois perfis de usuários com jornadas distintas e otimizadas:

👤 Para o Motorista (Cliente Final)

Sincronização OBD-II: Pareamento Bluetooth com o scanner do veículo.

Dashboard de Saúde: Visão simplificada do desgaste de componentes (óleo, filtros, correias) com indicadores visuais intuitivos (verde, amarelo, vermelho).

Comparativo de Preços: Busca por serviços mecânicos com listagem de valores de oficinas próximas (raio de 20 km).

Diário de Bordo Digital: Histórico completo de manutenções e serviços já realizados.

🛠️ Para o Mecânico (Parceiro)

Painel Corporativo: Gestão do perfil da oficina (endereço, especialidades, horário).

Gestão de Tabela de Preços: Ferramenta para atualização quinzenal de valores de peças e serviços (garantindo orçamentos sempre válidos para o motorista).

Captação de Clientes: Visualização de motoristas próximos buscando por orçamentos específicos.
